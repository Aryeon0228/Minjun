# 🐢 거북이 술래잡기

민준이를 위한 숨은 거북이 찾기 게임입니다.

마을 곳곳(집 뒤, 덤불 속, 나무 위, 연못, 우물, 건초더미, 구름 뒤…)에
여러 모양의 거북이가 숨어 있어요. 찾아서 누르면 점수가 올라갑니다.

## 노는 법

`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행됩니다.
설치할 것도, 인터넷 연결도 필요 없어요.

1. ▶ 를 누르면 시작
2. 마을에서 삐죽 나와 있는 거북이를 찾아서 누르기
3. 다 찾으면 다음 마을로!

## 다섯 살에 맞춘 부분

- **글자를 못 읽어도 됩니다** — 그림, 색, 소리로만 안내돼요
- **실패가 없습니다** — 시간 제한도, 게임 오버도 없어요. 틀려도 아무 일 없어요
- **막히면 도와줍니다** — 10초 동안 못 찾으면 거북이들이 꿈틀거리고,
  20초가 지나면 한 마리 자리에 반짝이는 동그라미가 나타나요
- **누르기 쉽습니다** — 거북이 주변을 넉넉하게 눌러도 잡히고,
  두 마리가 가까이 있으면 더 가까운 쪽이 잡혀요
- **찾으면 바로 반응합니다** — 소리, 색종이, 거북이 이름 말해주기

## 거북이 친구들

동글이 · 별이 · 하트 · 꽃송이 · 점박이 · 줄무늬 · 무지개 · 반짝이 — 여덟 마리

## 마을

레벨마다 마을 분위기가 바뀝니다: 낮 → 노을 → 밤 → 눈 (반복)

숨는 거북이는 3마리부터 시작해서 한 마리씩 늘어나고, 최대 9마리까지 나옵니다.
숨을 수 있는 자리는 마을에 16곳이 있고, 매번 무작위로 골라요.

## 만든 것

- `index.html` — 게임 전체 (HTML 한 파일, 외부 라이브러리 없음)
  - 그림은 전부 SVG로 그렸습니다
  - 소리는 Web Audio API로 만들었습니다 (음원 파일 없음)
  - 🔊 버튼으로 소리 끄기, 🔄 버튼으로 처음부터 다시
