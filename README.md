# 🐢 민준이의 게임

다섯 살 민준이를 위해 만든 게임들입니다.
둘 다 **HTML 파일 하나**라서, 내려받아 더블클릭하면 브라우저에서 바로 실행됩니다.
설치할 것도, 인터넷 연결도 필요 없어요.

| 파일 | 게임 | 조작 |
|---|---|---|
| `index.html` | 🐢 **거북이 술래잡기** — 마을에 숨은 거북이 찾기 | 마우스 / 손가락으로 누르기 |
| `turtle-simulator.html` | 🐢 **거북이 시뮬레이터** — 마을을 뛰어다니며 다 부수기 | 키보드 |

---

## 🐢 거북이 술래잡기 (`index.html`)

마을 곳곳(집 뒤, 덤불 속, 나무 위, 연못, 우물, 건초더미, 구름 뒤…)에
여러 모양의 거북이가 숨어 있어요. 찾아서 누르면 점수가 올라갑니다.

1. ▶ 를 누르면 시작
2. 삐죽 나와 있는 거북이를 찾아서 누르기
3. 다 찾으면 다음 마을로!

- 거북이 여덟 마리: 동글이 · 별이 · 하트 · 꽃송이 · 점박이 · 줄무늬 · 무지개 · 반짝이
- 숨는 자리 16곳 중 매번 무작위로, 3마리부터 시작해 최대 9마리까지
- 마을 분위기가 낮 → 노을 → 밤 → 눈 으로 바뀜
- 10초 동안 못 찾으면 거북이가 꿈틀, 20초가 지나면 반짝이는 동그라미로 알려 줌

휴대폰은 **가로로 돌려서** 해주세요.

## 🐢 거북이 시뮬레이터 (`turtle-simulator.html`)

"염소 시뮬레이터처럼 만들고 싶다"는 민준이의 요청으로 만들었습니다.
목표도 없고 끝도 없어요. 그냥 마을을 마음껏 어지르는 놀이터입니다.

### 조작 (키보드)

| 키 | 하는 일 |
|---|---|
| `←` `→` | 걷기 |
| `↑` | 점프 (물속에서는 위로 헤엄) |
| `↓` | 등껍질 속으로 쏙! 데굴데굴 굴러가며 다 쓸어버리기 |
| `Z` | 목 쭉! 물건을 물어서 끌고 다니기 (놓으면 던져짐) |
| `X` | 박치기 — 앞으로 확 돌진 |
| `R` | 마을 정리 (부순 것 원래대로) |

### 마을에 있는 것

마을은 가로로 **7,200픽셀**, 화면 여덟 개쯤 되는 길이입니다. 왼쪽 끝에서 출발해
`→` 를 따라가면 이런 곳들을 차례로 지나갑니다.

| 구역 | 있는 것 |
|---|---|
| 1~4 | 첫 상자 탑 · 수박 더미 · 화분과 나무통 · 트램펄린 · 미끄럼틀 |
| 5~8 | 작은 연못(헤엄) · 농장(울타리 · 건초더미 · **도망다니는 닭**) · 지붕 위 상자 · 커다란 탑 |
| 9 | **얼음판** — 쭈욱 미끄러집니다. 눈사람도 하나 |
| 10 | **볼링** — 핀 열 개를 등껍질로 굴러가서 한 번에 쓰러뜨리기 |
| 11 | **큰 연못 + 징검다리** — 수박과 공이 둥둥 떠 있어요 |
| 12 | **풍선** — 여섯 개가 줄에 매달려 흔들흔들. 물거나 박치기하면 **펑!** |
| 13 | **트램펄린 세 개 + 공중 발판** — 통통 튀어서 하늘 길로 |
| 14 | **큰 농장** — 닭 일곱 마리와 건초더미 |
| 15 | **큰 과일 시장** — 수박탑과 사과 피라미드 |
| 16 | **마지막 탑** — 여덟 층짜리. 꼭대기까지 올라가 보세요 |

### 다섯 살에 맞춘 부분

- **실패가 없습니다** — 시간 제한도, 게임 오버도, 죽는 것도 없어요
- **어디서도 갇히지 않습니다** — 턱이 있으면 알아서 올라가고, 막히면 밀어내고,
  같은 자리에서 계속 헛심을 쓰면 타고 넘어가고, 그래도 안 되면 빡쳐서 한 방에 날려 버립니다.
  `→` 만 계속 눌러도 마을 끝(7,200픽셀)까지 갈 수 있는 걸 확인했어요
- **키보드 연습** — 방향키와 `Z` `X` 만 쓰고, 안내가 화면 아래에 항상 보입니다
- **즉각 반응** — 부딪힐 때마다 소리, 색종이, 화면 흔들림
- 술래잡기에서 만난 **거북이 여섯 마리 중 하나를 골라서** 플레이합니다

## 만든 방법

- 각각 HTML 파일 하나. 외부 라이브러리, 이미지, 음원 파일 없음
- 그림은 전부 코드로 그렸습니다 (술래잡기는 SVG, 시뮬레이터는 Canvas)
- 소리는 Web Audio API로 그때그때 만들어 냅니다
- 시뮬레이터의 물리(쌓기, 무너지기, 날아가기, 물에 뜨기)는 직접 구현했습니다
